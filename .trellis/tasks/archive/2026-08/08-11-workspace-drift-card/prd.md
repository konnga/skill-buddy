# 工作台漂移卡联动 Skills 筛选

## Goal

点击工作台存在漂移卡后进入 Skills 并启用仅看漂移筛选

## Requirements

- 工作台四张统计卡中，仅“存在漂移”卡提供点击交互。
- 点击“存在漂移”卡后进入 Skills 视图，并自动启用现有“仅看漂移”筛选。
- 复用 `useSkills` 中已有的 `driftOnly` 状态，不新增漂移页面或重复筛选逻辑。
- 漂移数量为 0 时仍允许进入筛选结果，确保交互行为稳定且可预期。
- 其他三张统计卡保持纯信息展示，不添加点击、指针或按钮语义。
- Agent 与范围作为可组合的安装视图：项目范围可展开查看其 Agent，并支持查看单个项目 Agent。
- 范围导航只展示已配置的项目范围，不提供额外的“用户级”或“全局”入口；未选择项目范围时即查看跨范围结果。
- Skill 卡片的状态、启停目标、卸载目标和确认文案必须遵循当前 Agent 与范围条件，范围操作不得影响其他范围。
- 保留工作区中已有的 favicon 与设置页品牌图标改动。

## Acceptance Criteria

- [x] “存在漂移”卡支持鼠标点击、键盘聚焦和键盘触发。
- [x] 可点击卡片具备指针、悬停和焦点反馈，其他统计卡外观与行为保持不变。
- [x] 点击后显示 Skills 视图，且“仅看漂移”按钮处于启用状态。
- [x] Skills 列表只展示 `hasDrift` 为真的项目；没有漂移时显示现有空结果状态。
- [x] 不新增独立漂移状态，不复制现有过滤实现。
- [x] 项目范围下可展开 Agent 列表，并可查看该项目内的单个 Agent。
- [x] 侧边栏范围区域不再显示“用户级”或“全局”入口，项目范围及其 Agent 列表保持可用。
- [x] 项目范围中的启用、禁用与卸载仅作用于当前范围，确认文案不再提示全局操作。
- [x] Skill 卡片的禁用状态、开关提示与实际操作目标使用相同的 Agent + 范围条件。

## Notes

- 本任务为轻量交互改动，仅需 PRD。
